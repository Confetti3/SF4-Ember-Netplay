# Input glyphs

Original, unmodified 128-pixel PNG assets from **Kenney Input Prompts 1.5A**, distributed under CC0. See `License.txt`.

Source: https://kenney.nl/assets/input-prompts

Archive downloaded 2026-09-08: `kenney_input-prompts_1.5.zip`.
SHA-256: `AC2FCF599080B0F3BA2D174C9474DB6DF1A0E96FF0662580E2DA79A122AB78A1`.

Selected assets come from `Xbox Series/Double`, `Keyboard & Mouse/Double`, and `Generic/Double`. The runtime uses the original sprites; no replacement button shapes are drawn in code. Xbox menu defaults are physical A for Select and B for Back, independently of fighting mappings. Unidentified DirectInput shapes use the generic sprite with an explicit mapped LP/LK action label.

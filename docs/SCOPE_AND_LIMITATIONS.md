# Scope and acceptance

SF4 Ember Netplay is an experimental unofficial Windows USF4 port. The active product is Iroh private rooms, the existing spectator path, offline play and GGPO rollback. Public discovery, a rollback rewrite, a new renderer, remote infrastructure changes and publication are outside this implementation.

Legacy product code has been removed locally. Retirement is accepted only after the replacement passes actual SF4 host/join, fight, repeated rematch, leave/rejoin, offline and spectator testing with the old VPS unavailable, over direct and forced-relay paths. Different-network and clean-machine tests remain explicit gates. See EMBER_IMPLEMENTATION.md for the candidate's measured results.

# SF4 Ember Netplay v1.6.0

## Costume and colour grid

- **Costumes and colors are pictures again, all at once.** On a fighter's page, Select on Costume shows a card for every costume you own, each in the color you wear now. Select on a costume shows all of its colors together, and Select on a color saves both. The pad moves across the cards in every direction, and Back steps out without changing anything. Left and Right on the Costume and Color rows still change them in place.
- **From a room, Appearance opens the costume grid straight away,** and picking a color returns to the room.

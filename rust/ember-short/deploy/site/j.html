Join an Ember room

Someone invited you to an SF4 Ember Netplay room.

  1. Start SF4 Ember Netplay.
  2. Choose Online play, then Join room.
  3. Choose Paste invitation, then Join room.

The link works while the room is open. If it stops working, ask the host for a new one.

This page needs the code from an Ember room link, such as embernetplay.link/j#K7QM-4XRT-9PZD.

Ask the host to copy the short link again from the room menu.
